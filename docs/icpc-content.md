# Розбори ICPC

Маршрути: `/icpc` → `/icpc/[contest]` → `/icpc/[contest]/[problem]`.
Кожна добірка має власний slug; кожна задача — окрему статично згенеровану сторінку.

Дані та реєстр `icpcContests` розташовані у `content/icpc.ts`. Для наступного
змагання додайте до реєстру об’єкт із `slug`, `title`, `description`, `problems`.
Великі добірки можна винести в окремі модулі та імпортувати до реєстру.
Маршрути, картки й переходи між задачами формуються з реєстру автоматично.
Переходи між сусідніми задачами залишаються в межах поточної добірки.

Кожен `IcpcProblem` містить назву, літеру, slug, archiveId Algotester,
складність, короткий переказ, патерни з ознаками розпізнавання та посиланнями
на теорію, секції розбору, складність алгоритму й типові помилки.
Наприкінці сторінки шаблон завжди показує кнопку практики на Algotester.

Початкові джерела добірки 2024: умови Algotester 71092–71103 та наданий
користувачем короткий розбір A–L. Формати введення звірено з умовами;
власні приклади позначені як навчальні, псевдокод не видається за готовий
розв’язок, прийнятий системою. У C і K явно відокремлено недоведені в
джерелі структурні леми від доведень допустимості конструкцій.

Добірка 2025 винесена в `content/icpc/ukraine-2025-stage-1.ts` і підключена
до спільного реєстру: 13 задач A–M, умови 81392–81404, складності з наданого
списку. Додано виведення переходів C, два DSU-проходи для F, амортизований
аналіз J, доказ симетрій L і правильний порядок фарбувань M. Службовий
абзац про підготовку розбору прибрано зі спільного шаблону всіх задач.

Другий етап 2024 — `content/icpc/ukraine-2024-stage-2.ts`, 12 задач A–L.
Ідентифікатори задані явно: 71108, 71109, 71111–71120; пропуск 71110
не заповнюється. Опційне поле `externalUrl` зберігає оригінальні англомовні
посилання, зокрема `DisplayWithEditor`. Для C виправлено повноту перевірки:
потрібно перевірити також перестановку двох останніх елементів. Для D описано
інтерактивний протокол, для F — перевірку без перебору всіх n·m точок, для G —
явну конструкцію без рисунків, для H — конденсацію SCC замість топологічного
сортування початкового графа залежностей.

Перевірка: `npm test`, `npm run build`. Збірка має створити сторінку добірки
та всі її задачі в `out/icpc/`. Загальний lint може захоплювати сторонні
неіндексовані файли у `artifacts/`; для змін розділу запускайте oxlint з
явним переліком шляхів.
